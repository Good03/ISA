Known limitations
#LimitationImpact
01 Training cutoff 2018 — model has no knowledge of COVID crash (2020), the 2022 rate-hike bear market, or the 2023–24 AI rally Elevated test error post-2019
02 Univariate LSTM — Close price only; ignores volume, sentiment, macro indicators, earnings releases Cannot react to fundamentals
03 Point predictions — no confidence intervals or probability distribution; user cannot assess uncertainty Overconfidence risk
04 Single-step horizon — 1-day forecast only; not suited for multi-week portfolio planning Limited applicability
Improvement roadmap
01
Closed-loop feedback & auto-retraining
Capture user-flagged prediction errors via thumbs up/down. Persist actual vs predicted to a feedback store and trigger weekly retraining whenever rolling RMSE breaches a configured threshold.
closes #06addresses drift
02
Uncertainty quantification
Replace point estimates with predictive distributions: Monte-Carlo Dropout for the LSTM, conformal prediction for Ridge. Render a confidence band overlay so users can read reliability at a glance.
closes #04EU AI Act transparency
03
Live data & rolling retraining
Ingest daily OHLCV from Yahoo Finance (yfinance). Retrain on a rolling 3-year window so the model stays aligned with the prevailing regime without a full retrain from scratch.
closes #01, #03
04
Multivariate & sentiment features
Add trading volume, VIX, sector ETF returns and FinBERT-derived news sentiment to the LSTM input tensor. Moves the model meaningfully beyond the random-walk baseline.
closes #02
