Known Limitations
#LimitationImpact
1 Training cutoff 2018 — model has no knowledge of COVID crash (2020), rate-hike bear market (2022), or AI boom (2023–24) High prediction error on post-2019 data
2 Univariate LSTM — uses only Close price; ignores volume, news sentiment, macroeconomic indicators, earnings announcements Cannot react to fundamental events
3 Random-walk baseline — both models largely predict "tomorrow ≈ today"; R² is high because stock prices are autocorrelated, not because the model captures alpha Misleadingly good R² metrics
4 Point predictions only — no confidence intervals or probability distributions; user cannot assess prediction uncertainty Overconfident decision-making risk
5 Single-step horizon — only 1-day ahead prediction; not suitable for longer-term portfolio planning Limited practical applicability
6 No feedback loop — model does not learn from its own errors in production; performance may degrade silently over time Undetected model drift
Proposed Improvements
🔄
Feedback system
Collect user-flagged prediction errors via a thumbs-up/down UI widget. Log actual vs predicted into a feedback database. Use accumulated errors to trigger automatic weekly retraining when RMSE on recent data exceeds a threshold.
Closes limitation #6 Addresses model drift
📊
Uncertainty quantification
Replace point predictions with probability distributions using Monte Carlo Dropout (LSTM) or conformal prediction (Ridge). Display a shaded confidence band on the chart so users understand prediction reliability.
Closes limitation #4 EU AI Act transparency
🌐
Live data + rolling retraining
Integrate Yahoo Finance API (yfinance) for daily OHLCV updates. Retrain on a rolling 3-year window so the model stays calibrated to current market conditions without full retraining from scratch.
Closes limitations #1, #3
🧠
Multivariate + sentiment features
Add trading volume, VIX index, sector ETF returns, and news sentiment scores (e.g. FinBERT) as additional input features to the LSTM. This moves the model beyond the random-walk baseline.
Closes limitation #2
🤝
Ensemble model
Combine LSTM + Ridge + Chronos (fine-tuned) predictions via a meta-learner. Ensemble typically reduces RMSE by 10–20% compared to any single model and is more robust to distributional shifts.
Reduces overall risk
